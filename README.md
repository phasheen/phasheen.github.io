## Version control

This repository is initialized with `jj` in colocated mode, so it remains a
normal GitHub Pages Git repository while local history can be managed with
Jujutsu.

Useful commands:

```bash
jj status
jj log
jj diff
jj describe -m "Update homepage"
jj bookmark move main --to @
jj git push
```
